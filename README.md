# 🏷️ Preço Mudou - Analisador e Auditor de Flutuação de Preços em JavaScript

## 📌 Visão Geral do Projeto
O **Preço Mudou** é uma aplicação web interativa desenvolvida em JavaScript puro (Vanilla JS) focada em analisar a variação e a elasticidade de preços de produtos. O objetivo principal do projeto foi criar um algoritmo condicional capaz de comparar valores históricos, calcular a taxa de mudança e retornar feedbacks visuais em tempo real sobre inflação, deflação ou estabilidade de preços no mercado.

Projeto prático de lógica de programação desenvolvido durante a formação especializada na **OneBitCode**.

🔗 **Acesse a aplicação em produção:** [https://eduardocruz777.github.io/Mudanca-de-Preco/](https://eduardocruz777.github.io/Mudanca-de-Preco/)

---

## 🛠️ Tecnologias, Recursos Lógicos e Conceitos Aplicados
* **JavaScript Estrutural (Vanilla JS):** Desenvolvimento de funções condicionais complexas para validação e comparação de inputs numéricos monetários.
* **Manipulação Dinâmica do DOM:** Captura de eventos em tempo real (`addEventListener`) acoplados a botões interativos e injeção de respostas de texto e estilo no documento.
* **Lógica de Negócio (Precificação):** Aplicação prática de regras de mercado para identificar flutuações de preços (Aumento, Queda ou Preço Estável), simulando rotinas de sistemas de e-commerce e CRM.
* **Web Design Responsivo (CSS3):** Estruturação de interface limpa, moderna e adaptável a telas de smartphones e desktops através de folhas de estilos customizadas.
